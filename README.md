# 語音輸入（Windows）

按一下**右邊的 Ctrl** 開始說話，說完再按一下，就自動辨識、轉成台灣繁體中文，直接打在游標所在的位置。
語音辨識預設用 **Groq 雲端**（一樣是 whisper large-v3，一句不到 1 秒、不吃顯示卡）；斷網時自動改用本機顯示卡的 whisper。

> 目前進度：**M6 進階功能**（指令模式已完成；詞庫自動學習、翻譯模式、個人化風格、錄音時自動靜音待實測）。按一下說話 → 詞庫修正專有名詞 → AI 依上下文修錯字、刪贅字、處理口誤 → 打出來。
> 錄音時畫面下方有浮動小視窗，聽錯的字可以從選單一鍵加入詞庫；辨識引擎和 AI 校正來源都可以從選單切換。

---

## 第一次安裝（雙擊就好，不用打指令）

1. 雙擊資料夾裡的 **`install.bat`**。
2. 等它跑完（第一次大約 10 ~ 30 分鐘，主要是下載辨識模型，約 3GB）。
   畫面會一步一步顯示進度 [1/6] ~ [6/6]，有問題會用中文告訴你怎麼辦。
3. 最後會問你三件事：要不要在桌面建立捷徑、要不要開機自動啟動、要不要現在啟動。按 `Y` 或 `N`。

> **換到另一台電腦**：下載 https://github.com/kushini41-source/voice-input/archive/refs/heads/main.zip（不用登入），
> 解開後把資料夾放到桌面、改名成 `语音输入`，雙擊 `install.bat`，再放入 `api_key.txt`、`groq_key.txt` 兩把金鑰（GitHub 上沒有金鑰）。
> 之後要更新，重新下載同一個網址、把檔案蓋過去就好（金鑰、詞庫、紀錄不在裡面，不會被蓋掉）。
> 也可以直接把整個 `语音输入` 資料夾複製過去（放在桌面，資料夾名稱不要改），在那台電腦雙擊 `install.bat`。
> - `.venv` 資料夾可以不用複製（它只能在原本那台用，install.bat 會自動重建；複製過去也沒關係，壞掉會自動刪掉重建）。
> - 辨識模型（約 3GB）不在資料夾裡，那台會重新下載一次。
> - 你的詞庫、用字習慣、設定、API Key 都在資料夾裡，會一起帶過去。兩台之後各自學習，不會自動同步。
> - 資料夾裡有你的 API Key（`api_key.txt`），壓縮檔不要傳給別人。
> 安裝出錯想重來，直接再雙擊一次 `install.bat`，已經裝好、下載好的部分會自動跳過。

## 怎麼啟動

- **平常使用**：雙擊桌面的「語音輸入」捷徑，或資料夾裡的 `启动语音输入.vbs`。
  不會出現黑色視窗，大約 10 秒後右下角系統匣會出現藍色麥克風圖示。
- **開機自動啟動**：在系統匣麥克風圖示按右鍵，勾選「開機自動啟動」（再點一次就取消）。
- **測試／除錯**：雙擊 `执行语音输入.bat`。會開一個視窗即時顯示辨識紀錄，關掉視窗就結束程式。

## 怎麼用

| 動作 | 結果 |
|---|---|
| **按一下右 Ctrl** 開始說話（手可以放開），說完**再按一下** | 辨識後直接打出文字 |
| 錄音中**按一下 Shift**，再按右 Ctrl 結束 | **指令模式**：用說的叫 AI 改寫選取的文字、回答問題、幫你寫東西（見下方） |
| 錄音中**按兩下 Shift**，再按右 Ctrl 結束 | **翻譯模式**：說中文，打出翻譯好的英文（或日文、韓文…，見下方） |
| 錄音中按**第三下** Shift | 回到一般聽寫（按錯了可以這樣改回來） |
| 右 Ctrl 跟別的鍵一起按（例如右 Ctrl+C） | 照常當快捷鍵，不會錄音 |
| 錄音中或處理中按 **Esc** | 取消這一句，不會打出任何字 |
| 忘了按結束 | 錄超過 2 分鐘會自動結束並辨識 |

> 想換別的按鍵：改 `config.yaml` 的 `hotkey.key`（例如 `capslock`、`f13`、`mouse_x2` 滑鼠側鍵）。
> 想改回「按住說話、放開辨識」：把 `hotkey.mode` 改成 `hold`。

**浮動小視窗**（螢幕下方中央）：開始錄音後會出現「● 錄音中 00:03」和音量條；
結束錄音後顯示「整理中…」；打出來後顯示「✓ 已輸入」並淡出。它不會搶走游標，滑鼠也點不到它。
不想要的話，把 `config.yaml` 的 `ui.overlay` 改成 `false`。

系統匣圖示的顏色：灰色 = 載入中、藍色 = 待機、紅色 = 錄音中、黃色 = 處理中。

**系統匣右鍵選單**：

| 選單項目 | 做什麼 |
|---|---|
| 把上一句加入詞庫… | 跳出小視窗，顯示上一句「聽到什麼」和「打出什麼」，填「聽錯的字 → 正確的字」就存進詞庫，下一句馬上生效 |
| 查看最近 20 筆紀錄 | 看每一句從原始辨識到最後打出的過程；可以複製，或雙擊直接加入詞庫 |
| 辨識引擎 ▸ | 在 Groq 雲端、本機 faster-whisper、CapsWriter 之間切換（見下方「辨識引擎」） |
| AI 校正來源 ▸ | 在 Claude（雲端）和 Ollama（本機）之間切換 |
| 翻譯成 ▸ | 翻譯模式要翻成哪一種語言（英文、日文、韓文，可以在 `config.yaml` 自己加） |
| AI 校正 | 勾選＝開啟；取消＝不做 AI 校正 |
| 詞庫自動學習 | 勾選＝發現常聽錯的詞會問你要不要加進詞庫（見下方「詞庫自動學習」） |
| 個人化風格 | 勾選＝AI 校正照你的用字習慣寫（見下方「個人化風格」） |
| 錄音時自動靜音 | 勾選＝錄音時把其他程式的聲音關掉，錄完還原（見下方） |
| 立即整理我的用字習慣 | 馬上請 AI 從你的紀錄整理一次用字習慣（平常每說 30 句會自動整理） |
| 復原最近自動學的詞 | 把最近一次自動加進詞庫的詞拿掉（學錯時用） |
| 開機自動啟動 | 勾選＝開機自動執行 |
| 開啟詞庫／用字習慣／設定檔／日誌資料夾／程式資料夾 | 直接打開對應的檔案或資料夾 |
| 結束 | 關閉程式 |

**錄音時自動靜音**：開始錄音時，音樂、影片、LINE 通知聲這些其他程式的聲音會自動關掉，
結束（或按 Esc 取消）時馬上恢復，麥克風就不會收到背景聲音。
- 只動 Windows「音量混合器」裡各程式自己的音量，不動喇叭總音量；語音輸入的提示音和 Windows 系統音效照常。
- 你本來就靜音的程式，錄完不會被打開。
- Teams、Zoom 這類開會軟體預設不動（開會時才聽得到對方）。想讓 LINE 通話、Discord 也不被靜音，
  把 `LINE.exe`、`Discord.exe` 加進 `config.yaml` 的 `mute.skip_apps`。
- 想改成「調小聲」而不是完全靜音：`config.yaml` 的 `mute.mode` 改成 `lower`。
- 萬一程式在錄音中當掉，聲音會停在靜音；**重新開啟語音輸入就會自動還原**（也可以在 Windows 音量混合器手動打開）。
- 不想要：系統匣右鍵取消勾選「錄音時自動靜音」。

輸出方式是「暫時借用剪貼簿 → 貼上 → 把剪貼簿還原」，所以你原本複製的東西不會不見，
暫借的文字也不會出現在 Win+V 的剪貼簿紀錄裡。

## 指令模式（用說的叫 AI 做事）

1. 按一下右 Ctrl 開始錄音，**錄音中按一下 Shift**（浮動視窗會變成紫色的「指令模式」）。
2. 說出你要 AI 做什麼，再按一下右 Ctrl 結束。

| 情況 | 你可以說 | 結果 |
|---|---|---|
| **先選取一段文字**，要改它 | 「改短一點」「改正式一點」「翻成英文」「改成條列」「修正錯字」 | 直接**取代**選取的文字（不滿意可以按 Ctrl+Z 復原） |
| 先選取一段文字，問問題 | 「這段是什麼意思」「幫我摘要」「語氣會不會太兇」 | 畫面下方跳出**回答卡片**，原文不動 |
| 沒選取文字，要寫東西 | 「幫我寫一封請假信」「回覆說我明天下午三點到」 | 直接**打在游標位置** |
| 沒選取文字，問問題 | 「Python 的 list 跟 tuple 差在哪」 | 跳出回答卡片 |

- 回答卡片不會搶走游標：可以按「插入到游標位置」把回答打進去、按「複製」，或按「關閉」。開始下一次錄音時也會自動關掉。
- 在終端機（命令提示字元、PowerShell、Windows Terminal）裡，指令模式**不會讀取選取的文字**，
  因為在那裡按 Ctrl+C 會中斷正在執行的程式。
- AI 回應大約 2 ~ 4 秒。指令模式用 **Claude Sonnet 5.5**，會先稍微想一下再回答。
  想換模型：改 `config.yaml` 的 `command.model`（空白＝跟 AI 校正用同一個；`claude-haiku-5-5`＝最快；`claude-fable-5-1`＝最聰明但最貴），重開程式。

## 翻譯模式（說中文，打出外文）

1. 按一下右 Ctrl 開始錄音，**錄音中按兩下 Shift**（浮動視窗會變成青色的「翻成英文」）。
2. 用中文說你要講的話，再按一下右 Ctrl 結束。
3. 翻譯好的文字直接打在游標位置。

- **換語言**：系統匣右鍵 →「翻譯成」→ 選英文／日文／韓文。想加別的語言（法文、越南文…），
  改 `config.yaml` 的 `translate.languages`，重開程式。重開後會回到 `translate.target` 設定的語言。
- 會依目前的程式調整語氣：LINE 這類聊天軟體翻得口語簡短，Outlook、Word 翻得正式。
- 詞庫裡的專有名詞（例如 buy+1、Claude Code）照原樣保留，不會被翻掉。
- 說了「三點，不對，四點」只會翻更正後的；說「幫我寫一封信」也只會翻這句話，不會真的去寫信（要 AI 寫東西請用指令模式）。
- 翻譯大約 1.5 ~ 3 秒。AI 超過 8 秒沒回應或網路斷線時，會**改打出中文原文**並跳通知，不會讓你白講。
- 想翻譯已經打好的文字：選取它，用指令模式說「翻成英文」。

## 個人化風格（照你的用字習慣寫）

程式會從你說過的話、和你打出來後自己動手改的字，整理出「用字習慣」，
AI 校正和指令模式就照著寫。例如你常在句尾說「啦」「喔」，AI 就不會把它們當贅字刪掉。

- 習慣存在程式資料夾的 **`style.yaml`**（系統匣右鍵 →「開啟用字習慣」），**存檔後下一句就生效**：
  - `my_rules`：**你自己寫的**，程式不會動。例如在 `my_rules:` 下一行加 `  - 「喔」不要改成「哦」`、`  - 聊天：句尾不要加句號`
  - `learned`：**程式整理出來的**，每說 30 句自動更新一次。覺得哪條不對就刪掉；
    如果下次又出現，就在 `my_rules` 寫一條相反的規則（`my_rules` 優先）。
  - 開頭寫「聊天：」「技術：」「正式：」的只用在那個場景，沒寫的每個場景都用。
- 想馬上整理：系統匣右鍵 →「立即整理我的用字習慣」（大約 5 秒，會跳通知）。
- AI 整理出的每條習慣，都要能在你的紀錄裡找到至少 2 句證據（或你自己改過 1 次），找不到的會自動丟掉，避免 AI 亂猜。
- 紀錄只存文字、只存在你的電腦（`logs\style_samples.json`，最多 300 句）。第一次使用時會先從日誌匯入以前說過的話。
- 不想要：系統匣右鍵取消勾選「個人化風格」（重開程式後回到 `config.yaml` 的 `style.enabled`）。

## 個人詞庫（dictionary.yaml）

系統匣右鍵 →「開啟詞庫」。**存檔後幾秒內就會生效，不用重開程式。**
如果寫錯格式，會跳通知提醒，並繼續使用上一次正確的版本。

| 區塊 | 用途 | 例子 |
|---|---|---|
| `vocabulary` | 專有名詞。辨識時會提示給引擎，讓它更容易聽對，也不會被簡繁轉換改掉。常用的放前面 | `- Claude Code` |
| `replacements` | 強制替換：聽到左邊就換成右邊 | `"克勞德": "Claude"` |
| `rules` | 正規表示式替換（進階用） | 「2 點 5 版」→「v2.5」 |
| `snippets` | 語音快捷片語：整句剛好是左邊，就直接打出右邊 | 說「我的信箱」→ 打出 email |

**`replacements` 會比對「唸起來很像」的字**：左邊寫「克勞德」，就算辨識成「克老德」也會換成 Claude；
台灣口音常見的「捲舌不捲舌」「前後鼻音」也算像。不想要這個功能，或覺得換得太積極、太保守，
可以到 `config.yaml` 的 `dictionary` 區塊調整。只有一個字的詞只會完全比對，避免誤換。

### 詞庫自動學習（不用自己開詞庫）

**你改過的字，下次自動改對。** 語音輸入打出來後，你在輸入框裡把聽錯的詞改掉（例如把「深圖」改成「生圖」），
等你開始說下一句、或訊息送出時，程式就把「深圖 → 生圖」**直接加進詞庫**，螢幕右下角跳一張「✓ 已學會」卡片告訴你。

| 什麼情況 | 怎麼處理 |
|---|---|
| **你自己改的，而且兩個詞唸起來像**（聽錯，例如「深圖→生圖」「桌面板→桌面版」） | **直接學起來**，跳「已學會」卡片（按「復原」可以拿掉） |
| 你自己改的，中英混在一起（例如「拜加溫→buy+1」） | 直接學起來 |
| 你自己改的，但唸起來不像（可能是改主意，例如「明天→後天」） | 跳卡片**問你**要不要加 |
| AI 幫你改同一個詞（唸起來像），改到第 2 次 | 跳卡片問你 |
| AI 改到第 3 次（唸起來像） | 直接學起來 |
| AI 改的唸起來不像（AI 在改寫句子，例如「就是→顯示」）、或是「就是」「這個」這類常用詞 | 不學也不問 |

- **學錯了**：「已學會」卡片按「**復原**」，或右下角麥克風圖示右鍵 →「**復原最近自動學的詞**」。復原的詞以後不會再自動學。
- 自動學的詞在 `dictionary.yaml` 後面會標「# 自動學的 日期」，方便你檢查、手動刪掉。
- 詢問卡片的按鈕：「加入詞庫」「修改…」（字已填好，可以改一改再存）「不要」（以後不再問）。放著不管 30 秒會自己收起來。
- 想改回「一律先問我」：`config.yaml` 的 `learning.auto_from_edits` 改成 `false`。
- 做法是讀那個輸入框裡的字來比對（Windows 給螢幕報讀軟體用的方式），只在你的電腦上比對，**不存檔、不上傳**，**密碼欄不讀**。
  記事本、Word、LINE、Claude、Chrome 等一般程式都可以；終端機不會觀察。
- 只算「把詞換掉」：刪贅字、補標點、加字、整句重寫都不算。只改一個中文字時，會連旁邊的字一起帶上（避免只有一個字的詞誤換）。

不想要的話：系統匣右鍵取消勾選「詞庫自動學習」（重開程式後回到 `config.yaml` 的 `learning.enabled`）。

**怎麼加詞最有效**
- 某個英文詞常被聽錯 → 加進 `vocabulary`，例如 `- VS Code`。
- 某個詞總是被聽成固定的錯字 → 加進 `replacements`，左邊寫錯字、右邊寫正確的字。

另外，中文和英文之間會自動加一個空格（「改成async」→「改成 async」）；不想要的話，
把 `config.yaml` 的 `converter.space_between_chinese_english` 改成 `false`。

## AI 校正

辨識完、詞庫替換完，會再交給 Claude（目前用 **Sonnet 5.5**，比較會看上下文修同音錯字）做最後校正，大約多 1 ~ 1.5 秒：

- 修正同音錯字（短句也修）、刪掉「呃」「嗯」「那個」等贅字、被重複聽到的字
- **刪掉沒意思的語助詞**：啊、耶、啦、喔、欸、嘛…（「嗎」「呢」「吧」有意思的保留）。
  想保留語氣詞：`config.yaml` 的 `corrector.remove_particles` 改成 `false`
- 處理口誤：「明天三點，不對，四點開會」→「明天4點開會。」
- 補逗號、句號；**講很長一段（超過約 100 字）又講了不只一件事時，會在換話題的地方分段**（聊天軟體不分段）。
  長的一段 AI 會多給一點時間，不會因為太長來不及而整段沒標點
- 口述「逗號」「句號」「換行」「新段落」會變成符號；數字、時間、金額用阿拉伯數字；「...」會變成「……」
- **依目前的程式調整風格**（對照表在 `config.yaml` 的 `scenes`，可以自己加程式）：

| 場景 | 哪些程式 | 風格 |
|---|---|---|
| 技術模式 | VS Code、Cursor、終端機、Claude 桌面版… | 英文術語保持原樣；單句指令不加句號 |
| 聊天模式 | LINE、Telegram、微信、Discord… | 口語，短訊息不加標點 |
| 正式模式 | Outlook、Word、標題有 Gmail 的瀏覽器… | 完整標點、書面語；「第一…第二…」排成條列 |
| 一般模式 | 其他程式 | 補標點，句尾加句號 |

- 會參考**同一個程式裡最近 3 句**（5 分鐘內）來判斷用字。
- 詞庫裡的詞（例如 buy+1）會要求 AI 不准改掉。

**安全機制**：AI 超過 4 秒沒回應、網路斷線、或 AI 輸出怪怪的（擴寫、回答你的問題、加「好的，以下是…」前言、改掉詞庫的詞、改掉信箱或網址），
都會自動改用沒經過 AI 的版本，不會卡住。原因會記在日誌裡。

**金鑰失效或額度用完時會跳通知**（30 分鐘內同一個問題只通知一次）：照通知去 Claude Console 建新金鑰（**工作區要選 Default**）或儲值，貼進 `api_key.txt`。
這段期間字還是打得出來，只是沒有 AI 校正（不會補標點、不會修錯字）。

**換模型**：`config.yaml` 的 `corrector.model`。`claude-sonnet-5-5`（目前）比較聰明；`claude-haiku-5-5` 最快（一句約 1 秒，比 Sonnet 快約 0.3 秒，但比較少修到同音錯字）。改完重開程式。

**開關**：系統匣右鍵 →「AI 校正」可以隨時勾選／取消（關掉就是純本機模式，不連網）。
重開程式後會回到 `config.yaml` 的 `corrector.enabled` 設定。

費用：Sonnet 一句大約 0.05 台幣，講一千句約 50 台幣（Haiku 便宜大約 20 倍）；Claude Max 方案每月附的 API 額度就夠用。

## 辨識引擎（三種可以選）

| | Groq 雲端（預設） | faster-whisper（本機） | CapsWriter |
|---|---|---|---|
| 模型 | Whisper large-v3（在 Groq 的伺服器跑） | Whisper large-v3（你的顯示卡） | Qwen3-ASR（CapsWriter-Offline 內建） |
| 速度（每句辨識） | 約 0.6 ~ 1 秒，**長句也差不多**，跟顯示卡無關 | 4070 Ti 約 0.5 ~ 2 秒；2060 約慢 3 倍；跑作圖時會變慢 | 約 0.1 ~ 0.3 秒 |
| 需要 | 網路＋`groq_key.txt` 的金鑰（免費額度每天 2,000 句） | 不用網路 | CapsWriter 程式 |

- **Groq 雲端**（2026-10-22 起預設）：
  - 送出前會先在本機確認有人在說話，沒聲音就不送；頭尾的空白會剪掉。
  - **斷網、逾時（5 秒）、額度用完、金鑰失效**時，那一句自動改用本機 whisper，之後 1 分鐘內都先用本機，不會每句都等。
  - 本機 whisper 會一起載入著當備用，所以一樣會佔約 3 ~ 4GB 顯示卡記憶體。
  - 你的聲音會傳到 Groq 的伺服器辨識（Groq 預設不保留；在 Groq 網站的 Data Controls 打開 Zero Data Retention 就完全不保留）。
  - 金鑰放在程式資料夾的 `groq_key.txt`，到 [console.groq.com](https://console.groq.com) 的 API Keys 建立（`gsk_` 開頭）。
- **臨時切換**：系統匣右鍵 →「辨識引擎」→ 點選要用的。切換好之前會繼續用原本的引擎，不會中斷。
- **永久改用**：把 `config.yaml` 的 `asr.engine` 改成 `groq`、`whisper` 或 `capswriter`，重開程式。
- 選 CapsWriter 時，程式會**自動在背景啟動 CapsWriter 的伺服器**（只啟動伺服器，不啟動 CapsWriter 自己的按鍵程式），
  不用自己先開。CapsWriter 啟動失敗會自動改回 whisper，跳通知告訴你。
- 你的詞庫專有名詞也會一起提供給 CapsWriter 參考。

> ⚠️ **不要同時開 CapsWriter 自己的客戶端（start_client.exe）**：它也用 CapsLock，而且是用「鍵盤 hook」偵測按鍵，
> 跟這個程式同時開會互搶按鍵，也可能讓鍵盤卡住。

## 本機 AI 校正（Ollama，選用）

預設的 AI 校正用 Claude（雲端，要網路）。想完全不連網，可以改用本機 AI：

1. 到 [ollama.com](https://ollama.com/download) 下載安裝 Ollama。
2. 開「命令提示字元」，執行 `ollama pull qwen2.5:7b`（下載約 4.7GB 的模型）。
3. 系統匣右鍵 →「AI 校正來源」→「Ollama（本機）」。或把 `config.yaml` 的 `corrector.backend` 改成 `ollama`。

本機 AI 的校正品質通常比 Claude 差一些，而且會跟辨識引擎一起占用顯示卡記憶體。

## 設定

所有設定都在 **`config.yaml`**（系統匣右鍵 →「開啟設定檔」）。改完存檔後，
從系統匣按「結束」再重新啟動才會套用。常用的有：

| 設定 | 說明 | 預設 |
|---|---|---|
| `hotkey.key` | 錄音熱鍵：`right_ctrl`、`capslock`、`f13`、`mouse_x2`（滑鼠側鍵）等 | `right_ctrl` |
| `hotkey.mode` | `toggle` 按一下開始、再按一下結束；`hold` 按住說話、放開辨識 | `toggle` |
| `audio.device` | 指定麥克風（填名稱的一部分，例如 `MU5000`），留空用 Windows 預設 | 空白 |
| `audio.beep` | 開始／結束錄音時發出提示音 | `true` |
| `asr.whisper.model` | 辨識模型，越大越準 | `large-v3` |
| `dictionary.fuzzy_threshold` | 詞庫「唸起來很像」要多像才換，1.0 = 完全同音才換 | `0.85` |
| `converter.protect` | 不准簡繁轉換改動的詞（例如「項目」不會被改成「專案」） | 已內建幾個 |
| `converter.fixes` | 簡繁轉換斷詞錯誤的修正表（例如「這隻能 → 這只能」） | 已內建幾組 |
| `output.type_apps` | 這些程式改用逐字輸入，而不是貼上 | 空白 |
| `debug.save_history` | 把每次的錄音和結果存到 `history` 資料夾，方便除錯 | `false` |

## 這一版解決的舊問題

- **按右 Alt 整個鍵盤當機**：舊版雖然用輪詢偵測熱鍵，但打字時用的 `keyboard` 套件會偷偷裝上鍵盤 hook。
  新版完全拿掉這個套件，改用 Windows 原生的剪貼簿貼上和 `SendInput`，沒有任何 hook。
  如果想用右 Alt 當熱鍵也可以，程式會自動避免放開 Alt 時跳出選單列。
- **GPU 其實沒有用到**：舊版缺少 cuBLAS 的 DLL，一直默默用 CPU 跑 medium 模型。
  現在 `cuda_libs` 資料夾已經放好 DLL，實際用的是顯示卡加 large-v3，一句話辨識大約 0.3 秒。
- **第一次說話特別慢**：啟動時會先暖機一次。
- **新舊版同時開**：新版會擋住舊版，也不能重複開兩份。

## 常見問題

**按右 Ctrl 沒反應？**
看系統匣圖示是不是藍色。如果是灰色，代表還在載入；如果是暗紅色，代表發生問題，
請看 `logs\voice_input.log` 最後幾行。

**在某些程式裡打不出字？**
如果那個程式是用「系統管理員身分」執行的，一般權限的程式沒辦法送字給它。
可以把語音輸入也用系統管理員身分執行，或把那個程式加進 `output.type_apps`。

**跳出「改用 CPU 模式」的通知？**
代表顯示卡加速沒有成功，程式已經自動改用 CPU，可以照常使用，只是比較慢。
重新雙擊一次 `install.bat` 通常就會修好（它會重新準備 `cuda_libs` 裡的檔案）。

**某個詞一直被聽錯？**
說完那句之後，系統匣右鍵 →「把上一句加入詞庫…」，填聽錯的字和正確的字。
同一個詞如果每次被聽成不一樣的字，就多加幾次，或勾選「也加入專有名詞」讓辨識引擎一開始就比較容易聽對。
